# TV0012~TV0016 파일과 네임스페이스

| ID | 규칙 |
|---|---|
| TV0012 | 네임스페이스는 `TopView` + 폴더 경로(공백 제거). `Components/`와 `Systems/` 아래는 하위 폴더와 관계없이 `TopView.Components`, `TopView.Systems` |
| TV0013 | 파일 하나에 타입 하나 |
| TV0014 | 파일 이름은 타입 이름. partial 파일은 `타입이름.역할.cs`(역할은 PascalCase) |
| TV0015 | partial 타입에는 본 파일 `타입이름.cs`가 있어야 한다 |
| TV0016 | partial 타입의 파일은 같은 폴더에 둔다 |

스크립트 루트(`Assets/Scripts/`) 밖의 파일은 검사하지 않는다.

## 위반 다섯 가지

```csharp path=Assets/Scripts/Core/Mismatch.cs
namespace TopView.Wrong // 경고: TV0012
{
    public class Other { } // 경고: TV0014
    public class Second { } // 경고: TV0013
}
```

```csharp path=Assets/Scripts/Core/NoNamespace.cs
public class NoNamespace { } // 경고: TV0012
```

`Split`은 본 파일 `Split.cs`가 없고, 파일이 `Core/`와 `Systems/`에 흩어져 있다. `Split.bad.cs`는 역할 이름이 소문자이고, `Systems/` 폴더인데 네임스페이스가 `TopView.Core`다.

```csharp path=Assets/Scripts/Core/Split.Part.cs
namespace TopView.Core
{
    public partial class Split { } // 경고: TV0015, TV0016
}
```

```csharp path=Assets/Scripts/Systems/Split.bad.cs
namespace TopView.Core // 경고: TV0012
{
    public partial class Split { } // 경고: TV0014
}
```

## 올바른 배치는 통과

폴더 이름의 공백은 뺀다(`View Systems` → `ViewSystems`). `Components/Movement/`는 `TopView.Components`, `Systems/Movement/`는 `TopView.Systems`다. `World.cs`와 `World.Enemy.cs`는 올바른 partial이다. 스크립트 루트 밖의 파일은 검사하지 않는다.
