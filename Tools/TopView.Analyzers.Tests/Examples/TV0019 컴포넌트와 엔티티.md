# TV0019 컴포넌트·엔티티는 struct와 public 필드

이름이 `~Component`나 `~Entity`로 끝나는 타입과, 이름이 접미사 자체인 엔티티 칸(`Entity`)은 struct로 만들고, 인스턴스 필드를 모두 public으로 둔다.
static 필드와 상수는 검사하지 않는다.

## class인 엔티티와 private 필드는 경고

```csharp
namespace TopView.Components
{
    public struct GoodComponent
    {
        public int value;
        public static int SHARED;
    }

    public struct BadComponent
    {
        public int value;
        private int _hidden; // 경고: TV0019
    }

    public class WrongEntity { } // 경고: TV0019
}
```

## 엔티티 칸(`Entity`)도 같다

```csharp
namespace TopView.Entities
{
    public struct Entity
    {
        public int generation;
        private int _hidden; // 경고: TV0019
    }
}
```
