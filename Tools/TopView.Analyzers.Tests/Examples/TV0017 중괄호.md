# TV0017 중괄호는 다음 줄에 (Allman)

여는 중괄호 `{`는 앞 코드와 같은 줄에 두지 않고 다음 줄에 둔다.
한 줄로 끝나는 초기화식(`new Sample { Value = 1 }`)과 자동 프로퍼티(`{ get; set; }`)는 통과한다. 초기화식이 여러 줄이면 `{`를 다음 줄로 내린다.

## 같은 줄의 중괄호는 경고

```csharp
namespace TopView.Core
{
    public class Sample { // 경고: TV0017
        public int Value { get; set; }

        public int Computed
        {
            get { return 0; } // 경고: TV0017
        }

        public void Run()
        {
            if (Value > 0) { // 경고: TV0017
                Value = 0;
            }

            Sample single = new Sample { Value = 1 };
            Sample multiline = new Sample { // 경고: TV0017
                Value = 1
            };
            Sample allman = new Sample
            {
                Value = 1
            };
        }
    }
}
```
