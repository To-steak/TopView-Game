# TV0018 멤버 순서

클래스와 struct의 멤버를 이 순서로 둔다.

1. public 필드
2. public 프로퍼티
3. `[SerializeField] private` 필드
4. private 필드 (`static readonly` 포함)
5. private 프로퍼티
6. const
7. public 생성자
8. public 메서드
9. private 메서드 (Unity 메시지 포함)

이 아홉 종류에 들지 않는 멤버(internal·protected 멤버, 이벤트, private 생성자, 명시적 인터페이스 구현)는 어디에 있어도 된다. partial 타입은 파일마다 따로 본다.

## 올바른 순서는 통과

```csharp
using UnityEngine;

namespace TopView.Core
{
    public class Ordered : MonoBehaviour
    {
        public int publicField;
        public int PublicProperty => 0;
        [SerializeField] private int _serialized;
        private int _private;
        private static readonly int HASH = 1;
        private int PrivateProperty => 0;
        private const int LIMIT = 1;
        public Ordered() { }
        public void PublicMethod() { }
        private void PrivateMethod() { }
        internal void Unchecked() { }
    }
}
```

## 앞 묶음이 뒤 묶음 뒤에 오면 경고

```csharp
namespace TopView.Core
{
    public class Disordered
    {
        private const int LIMIT = 1;
        public int publicField; // 경고: TV0018
        private void PrivateMethod() { }
        public void PublicMethod() { } // 경고: TV0018
    }
}
```
