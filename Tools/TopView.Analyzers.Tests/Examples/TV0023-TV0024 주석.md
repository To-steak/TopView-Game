# TV0023~TV0024 주석

| ID | 규칙 |
|---|---|
| TV0023 | public 메서드에 한국어 XML 문서 주석. `<summary>` 필수, 매개변수마다 `<param>`, 반환값이 있으면 `<returns>` |
| TV0024 | public 필드 선언 바로 윗줄에 한국어 주석 |

"한국어"는 한글이 한 글자라도 있는지로만 본다.
재정의(`override`)·인터페이스 구현 메서드, private 메서드, enum 값은 검사하지 않는다.
속성을 윗줄에 따로 둔 필드(`[Header]` 등)는 속성과 선언 사이의 주석도 "바로 윗줄"로 인정한다.

## public 필드 주석

`noComment`는 주석이 없고, `englishComment`는 주석에 한글이 없고, `headerOnly`는 속성만 있고 주석이 없다.

```csharp
using UnityEngine;

namespace TopView.Core
{
    public class Sample
    {
        // 현재 탄약 수
        public int currentAmmo;
        public int noComment; // 경고: TV0024
        // ammo count
        public int englishComment; // 경고: TV0024
        [Header("Grid")]
        // 헤더 아래 주석
        public int belowHeader;
        [Header("Only")]
        public int headerOnly; // 경고: TV0024
    }
}
```

## public 메서드 문서 주석

`Missing` 줄의 경고 셋은 영어 `<summary>`, 빠진 `<param>`(first, second), 빠진 `<returns>`다.

```csharp
namespace TopView.Core
{
    public class Sample
    {
        /// <summary>
        /// 값을 돌려준다.
        /// </summary>
        /// <param name="value">돌려줄 값</param>
        /// <returns>받은 값</returns>
        public int Good(int value)
        {
            return value;
        }

        public void NoDocumentation() { } // 경고: TV0023

        /// <summary>
        /// Adds values.
        /// </summary>
        public int Missing(int first, int second) // 경고: TV0023, TV0023, TV0023
        {
            return first + second;
        }

        public override string ToString()
        {
            return string.Empty;
        }

        private void PrivateWithoutDocumentation() { }
    }
}
```
