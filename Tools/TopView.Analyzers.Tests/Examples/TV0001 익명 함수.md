# TV0001 익명 함수 금지

람다식(`() => …`, `x => …`)과 익명 메서드(`delegate { … }`)를 쓰지 않는다. 콜백이 필요하면 메서드를 만들고 이름을 넘긴다.
식 본문 멤버(`public int Count => 0;`)는 익명 함수가 아니라서 통과한다.

## 람다와 익명 메서드는 경고, 식 본문과 메서드 이름은 통과

```csharp
namespace TopView.Core
{
    public class Sample
    {
        public int Count => 0;

        public void Run()
        {
            System.Action first = () => { }; // 경고: TV0001
            System.Action<int> second = value => { }; // 경고: TV0001
            System.Action third = delegate { }; // 경고: TV0001
            System.Action named = Run;
        }
    }
}
```
