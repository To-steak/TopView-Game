# TV0003 중첩 타입 금지

다른 타입 안에 타입(class, struct, enum, interface, delegate)을 선언하지 않는다. 자기 이름의 파일로 꺼낸다.

## 타입 안의 타입은 경고, 바깥 타입은 통과

```csharp
namespace TopView.Core
{
    public class Sample
    {
        private enum Mode { First } // 경고: TV0003
        public class Inner { } // 경고: TV0003
        public delegate void Callback(); // 경고: TV0003
    }

    public class Other { }
}
```
