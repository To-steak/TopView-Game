# 규칙 예시 문서 읽는 법

이 폴더의 문서는 정적 분석기(TV 규칙)가 **어떤 코드에 경고하고 어떤 코드는 통과시키는지**를 예시로 보여 준다.

- 줄 끝에 `// 경고: TV0006`이 붙은 줄은 그 경고가 **나와야 하는** 줄이다.
- 표시가 없는 줄은 경고가 **나오면 안 되는** 줄이다.
- `dotnet test Tools/TopView.Analyzers.Tests`가 이 문서의 예시를 그대로 컴파일해서, 분석기가 문서와 똑같이 경고하는지 검사한다. 그래서 문서와 분석기는 어긋날 수 없다.
- 규칙을 바꾸고 싶으면 예시를 보고 "이 줄은 통과여야 한다"처럼 말하면 된다. 분석기 코드는 그에 맞춰 고친다.

이 README는 검사하지 않는다.

## 문서 쓰는 법

문서 맨 위의 `분석기:` 줄이 검사할 분석기를 정한다. `##` 제목 하나가 검사 하나이고, 그 아래 코드 블록들을 한 번에 컴파일한다.

```csharp
namespace TopView.Core
{
    public class Sample
    {
        public void Run()
        {
            System.Action callback = () => { }; // 경고: TV0001
        }
    }
}
```

코드 블록 여는 줄에 `path=경로`를 적으면 그 경로의 파일로 컴파일한다(파일·네임스페이스 규칙용). 적지 않으면 `Assets/Scripts/Core/Sample.cs`다. `assembly=이름`을 적으면 그 어셈블리 이름으로 컴파일한다.
