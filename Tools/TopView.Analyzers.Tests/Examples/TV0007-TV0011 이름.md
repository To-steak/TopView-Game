# TV0007~TV0011 이름 규칙

| ID | 규칙 |
|---|---|
| TV0007 | 이름 형식. 타입·메서드·프로퍼티·enum 값은 `PascalCase`, public 필드·지역 변수·매개변수는 `camelCase`, private 필드는 `_camelCase`, 상수와 `static readonly` 필드는 `UPPER_SNAKE_CASE` |
| TV0008 | bool 이름은 `is`, `has`, `can`으로 시작 |
| TV0009 | 줄임말 금지. 금지 단어 목록(`idx`, `pos`, `cnt`, `tmp`, `info`, 소문자 `hp`·`ui`·`id` 등)에 있는 단어만 잡는다 |
| TV0010 | 한 글자 이름 금지 (`i`, `x`) |
| TV0011 | 머리글자 약어 금지 (`UIScale`, `HP`) |

검사하지 않는 이름: 재정의(`override`)·인터페이스 구현처럼 외부가 정한 이름, Unity 메시지와 그 매개변수, 제네릭 타입 매개변수(`T`), 인터페이스 앞의 `I`.
